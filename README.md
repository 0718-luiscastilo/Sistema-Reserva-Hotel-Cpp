
# 🏨 Sistema de Reservas de Hotel en C++

## 📌 Descripción

Este proyecto es una aplicación de consola desarrollada en C++ que simula un sistema básico de reservas de hotel.

Permite registrar huéspedes, seleccionar habitaciones, calcular costos y generar estadísticas generales del hotel.

---

## 🚀 Funcionalidades

- Registro de múltiples reservas
- Almacenamiento de:
  - Nombre del huésped
  - Tipo de habitación
  - Cantidad de noches
- Validación de habitaciones:
  - Simple
  - Doble
  - Lujo
- Cálculo automático del costo por reserva
- Cálculo del ingreso total del hotel
- Cálculo del promedio por huésped
- Conteo de habitaciones reservadas por tipo
